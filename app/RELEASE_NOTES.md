## Nexus Ark リリースノート

## [0.3] - 2026-07-12

ペルソナが「調べる・作る・書き残す」を自分でこなせるようになる**エージェント委任**を中心に、手紙箱・クローゼット・アトリエ・カレンダーなど、暮らしの新機能をまとめてお届けします。不具合等のご報告や感想をいただけるととても助かります。

### ✨ 新機能
- **エージェント委任 — ペルソナに「お願い」できるようになりました**: 長めの調査・整理・ファイル作業・アプリ制作を、ペルソナが裏方の作業エージェントへ任せられる仕組みを追加しました。会話を止めずに裏で作業が進み、でき上がるとペルソナが報告してくれます。「自律行動 → アトリエ・委任」で有効化し、任せてよい権限の範囲（読み取りのみ〜フル）を選べます。タスクが指定した作業範囲の外を必要とする場合は、勝手に進めず確認待ちで停止します。
  - **ノウハウが経験から育つ（プレイブック育成）**: ペルソナが「この種類の依頼はこう進めると良かった」という改善案を提案し、「📚 プレイブック → 🌱 育成」であなたが「採用」すると以後の委任に反映されます（採用するまで反映されないので安心）。使うほどに、あなた好みの段取りが蓄積されていきます。
  - **調べた結果が“知識”として残る**: 委任したディープリサーチの成果を本文で受け取り、研究ノートへ取り込めます。取り込んだ内容は後の会話でも自然に思い出せる永続知識になります。「調べて報告して終わり」が「調べて学びとして蓄積する」へ変わります。
  - **実行中の委任へ途中指示**: 裏で動いている作業を止めずに「結論を急がず根拠の確認を優先して」などの方向修正を送れます（委任タスク実行ログの「🧭 実行中タスクへの途中指示」）。
  - **モデルの自動切り替え**: 委任の実行モデルを fast / balanced / deep として登録し、タスク種別やロールに合わせて自動で切り替えられます。
- **📮 手紙箱**: ペルソナがあなた宛の長文の手紙を残せるようになりました。通知には収まらない長さの内容（自律行動中に考えたことなど）が、チャット画面の「📮 手紙箱」に届きます。未読の手紙があることはペルソナ自身も把握しており、会話の中で触れることがあります。読み終えた手紙は本体から選択削除でき、Nexus Ark Liteでも「管理」内の「ノート」に続く手紙箱から閲覧・既読同期できます。
- **ペルソナのアトリエ — 作品づくりの場**: ペルソナが自分の作品（文章・画像・Webアプリ）を作って保管する「アトリエ」を追加しました。作れるアプリは3D表現（Three.js）や本格的なUI（Vue）に対応し、スマホのホーム画面に置いてオフラインでも動かせます。ペルソナは完成品を自分でスクリーンショット確認してから届けます。
- **クローゼット／外見システム**: 「クローゼット・アイテム」タブで、ペルソナとあなたの外見・服装・着用アイテムを管理できるようになりました。「🪞 姿見」で現在の姿をプレビュー生成でき、登録した装いは会話や画像生成にも反映されます。
- **カレンダー連携**: 左カラムの共通設定から、Googleカレンダーと連携できるようになりました。ペルソナ専用のカレンダーを個別設定から指定すれば、ペルソナが自由にカレンダーに書き込むこともできます。
- **スマホから研究ノート・創作ノートを編集**: Nexus Ark Lite（スマホ）で、ペルソナの研究ノート・創作ノートを閲覧に加えて編集・保存できるようになりました。スマホから扱える情報は今後の更新でも順次広げていく予定です。
- **睡眠時記憶整理の手動実行**: 「記憶・ノート」タブの「🛠️ 記憶のメンテナンス」から、夜間に行われる記憶整理（日記・夢・記憶索引の更新）をいつでも手動で実行できるようになりました。
- **📊 API使用量の概算パネル**: 共通設定のサイドバーには今日・今週・今月の概算金額だけをコンパクトに表示し、詳しい用途別・モデル別・プロバイダ別の内訳はポップアップで広く確認できます。会話・自律行動・委任に加えて画像生成も集計され、単価未登録の画像モデルは金額を盛らず回数だけ記録します（音声合成は未集計）。各応答にもその回の概算コストが表示されます。
- **使い方ガイドを同梱・オリヴェの知識も最新に**: 機能別のユーザーガイド（最初の設定ガイド付き）を同梱しました（左カラム一番下）。案内役ペルソナのオリヴェも最新機能を学び直したので、「スマホから使うには？」「委任って何？」など、使い方はアプリの中でオリヴェに直接聞けます。
- **再起動ボタン**: アップデートメニューに再起動ボタンも併設しました。

### 🔧 修正・改善
- **画面の操作感を統一（UI洗練）**: 各メニューの読み込みボタンを内容の上部へ移動し、名前を「🔄 読み込む」「🔄 最新の状態に更新」「🔄 一覧を更新」の3種類に統一しました。各設定ブロックには「変更は自動保存されます」「保存ボタンが必要です」などの保存方式が表示されるようになりました。
- **記憶の信頼性を強化**: 夢日記が記憶検索に確実に含まれるようにし、記憶索引の重複を整理しました。睡眠時記憶整理が特定条件で丸ごとスキップされる問題や、長時間の索引更新が途中で止まりやすい問題も修正しています。
- **データ保護の強化**: 記憶・設定・ノートなどの保存処理に同時書き込み保護を導入し、設定ファイルには階層バックアップ（毎時・毎日・異常検知時）を追加しました。
- **API費用の節約（キャッシュ効率化）**: Gemini・OpenAI・Anthropic各社のプロンプトキャッシュが効きやすいよう内部を最適化しました。長い会話ほど費用が下がりやすくなります。チャットの各応答にはキャッシュのヒット率がバッジで表示され、未ヒット時も「💾 キャッシュ 未ヒット」と分かるようになりました。より積極的にキャッシュする「Gemini Explicit キャッシュ（有料・実験）」も選べます（「⚙️ 設定 → 個別 → ⚡ AIモデルプロバイダ設定（このルーム）」内。削除せずに休ませる「一時停止」機能・解説ポップアップも用意しています）。
- **ツイートの重複投稿を防止**: ペルソナのTwitter (X) 投稿で、直近の投稿と似すぎる内容は自動で気づいて言い直すようになりました。
- **自律行動の安定化**: モデル過負荷時に長時間リトライし続ける問題、同名ツールの重複でエラーになる問題などを修正しました。通知禁止時間帯でも、その日の睡眠時記憶整理は優先して実行されます。
- **応答が空になる問題を修正**: 思考の長いモデル（Gemini 3系など）で、まれに本文が空の応答が返る問題を修正しました。感情表現のタグが本文に混ざる問題も解消しています。
- **Discord / LINE の修正**: ルーム別の「履歴送信件数」設定が外部連携で反映されないバグと、タイムスタンプが除去されず残る問題を修正しました。
- **起動の高速化**: 天気サービスが不調なときに起動や会話が余計に待たされる問題を抑制しました。
- **ローカルプラグインの修正**: 承認したライブラリ依存が再起動後に消える問題を修正しました。
- **天気ステータスをその場で更新**: 共通設定の「天気・環境連携設定」に「🔄 最新の天気に更新」ボタンを追加しました。設定を保存し直さなくても、現在の環境ステータスを最新化できます。

## [0.2.9.2] - 2026-06-07
### ✨ 新機能
- **スマホ向け Nexus Ark Lite PWA / API Gateway**: スマホから使える軽量専用アプリ Lite PWA と、その窓口になる API Gateway を追加しました。使い方は「外部接続」>「API Gateway / Lite」タブをご覧ください。
  - **Lite PWAの機能**: Web Push通知に対応。通知本文プレビューのオン/オフも選べます。Twitter下書きの承認/却下、現在地移動、自律行動のオンオフ、研究ノート・創作ノートの閲覧、文字列マスク機能、テーマカラー選択、等の機能が使えます。
  - **外部連携用APIの拡張**: 外部ツール、自作アプリなどからHTTP/JSONでNexus Arkへイベントを送れる API Gateway を追加。接続用Tokenをクライアントへ直接置かないためのToken中継サンプルも同梱しています。
- **ローカル音声生成エンジン対応**: AivisSpeech / VOICEVOX / COEIROINK などのVOICEVOX互換HTTP APIを、APIキー不要のTTS候補として使えるようになりました。
- **リアルタイムお天気連動機能**: 共通設定メニューの「天気・環境連携設定」から設定し取得したお天気情報を、情景描写やペルソナの会話に反映させることができるようになりました。気温・天気・日出没時刻に応じた動的な体感季節（「初夏」「早春」等）や伸縮時間帯（「夜」「深夜」等）の追加や気温に応じた冷暖房器具のオンオフ描写で、情景描写がより細やかに。

### 🔧 修正・改善
- **記憶・自律行動の安定性を改善**: Working Memoryの旧形式混在を整理し、自律行動で主行動ツールが選ばれやすいよう調整しました。Anthropic直接接続時に自律行動の終了処理でエラーになる問題も修正。
- **細かなUI不具合を修正**: 季節・時間指定が起動時に反映されない問題、Twitter下書き画像差し替え時に古いプレビューが残る問題、研究ノートの過去アーカイブへ到達しにくい問題、チャットログ表示時の不正画像パス検出エラー等を修正。
- **Discord連携のバグ修正**: interaction followup送信で添付ファイルがない応答に `files=None` を渡してしまい、AI応答生成後に `NoneType is not iterable` でエラー扱いになる問題を修正
- **OpenAI互換のTTSモデル選択メニューを改善**:  OpenAI互換TTSプロバイダで個別接続プロファイル選択、プロファイル別TTSモデル/声候補の取得・絞り込み、xAI/Groq TTSの実生成対応を追加しました。

## [0.2.8] - 2026-05-30
### ✨ 新機能
- **記憶・自律システムの大幅アップデート**: 記憶システムを「保存→検索→忘却」の直線的なモデルから、「保存→検索→深化→行動後の振り返り→次の行動へつなぐ」循環型へ改良しました。Research Threads、Working Memory、未解決の問い、目標、Action Memoryがより連動し、ペルソナが継続中の関心や作業を見失いにくくなります。
- **Skills / 手順記憶**: うまくいった作業手順や、繰り返し使う確認手順を記憶できる「Skills / 手順記憶」を追加しました。知識タブから共通Skill・ルーム専用Skillを確認、作成、編集できます。
- **音楽推薦カード**: ペルソナが曲名・アーティスト・推薦理由・各サービスの検索リンクをまとめた音楽推薦カードを作れるようになりました。
- **「司会AIで次の発言者を選ぶ」機能**: グループ会話モードで、発言順を内部司会AIに任せらるようになりました。また、最大3巡までユーザー抜きで会話を続けられます。
- **Discord連携の拡張**: ルームごとにDiscord Botを割り当てられるようになり、複数のペルソナを別々のBotとして扱いやすくなりました。Discordのスラッシュコマンドにも対応し、グループ会話モード（Beta）では複数のペルソナを指定して、内部司会AIが次の話者を選びながら会話を進められます。
- **音声入力・音声生成の拡張**: スマホやPCのマイク入力から文字起こしして送信しやすくなりました。音声生成はGeminiに加えてOpenAI公式、OpenAI互換プロファイル、ElevenLabsなどをルームごとに選べます。

### 🔧 修正・改善
- **思考ログ表示とGemini設定の改善**: Gradio 6の思考ログ表示を保ったまま、思考ログ用のタグ文字列が本文へ混ざりにくくしました。Gemini系モデルのネイティブ思考ログを軽く促すよう調整し、共通設定のGoogleモデル欄からThinkingレベルを選べるようにしました。
- **チャットログ保護の強化**: 過去ログの再生成・削除時に別月のログへ影響が出る問題を修正し、対象メッセージをより正確に特定するようにしました。
- **自律行動の見やすさと安定性を改善**: 自律行動中の内部ツール結果をチャット欄に大量表示せず、必要な内容だけ要約して表示するようにしました。行動後の振り返り、429/503エラー時の再試行、ツール引数の補正も強化しています。
- **知識・記憶まわりのUI改善**: 知識タブの初期表示で、過去に追加したファイルが「未読込」なのか「存在しない」のか分かりやすくしました。エンティティ記憶の重複整理、休眠・復帰、統合操作も扱いやすくなっています。
- **外部連携の改善**: X(Twitter)の取得系ツールを整理し、新着のみ確認しやすくしました。下書きキューや履歴の表示更新、Premium文字数判定、外部連携の規約・免責事項表示も改善しています。
- **Discord Bot設定の更新**: スラッシュコマンド対応を反映するため、既に登録済みのDiscord BotはDeveloper Portal側の設定や招待URLの修正が必要になる場合があります。外部連携タブの案内に沿って、`applications.commands` scopeなどの設定を確認してください。
- **画像生成・通知・モデル設定の修正**: Pollinations.ai画像生成が環境によってブロックされる問題を回避しやすくしました。アラーム通知と通常通知の送信先を分けられるようにし、ルーム個別AI設定を共通設定へ戻した際の挙動も整理しました。
- **動作負荷とメモリ使用量の改善**: Gradio 6環境での入力中CPU負荷、ルーム切替時の重さ、RAG検索後のメモリ保持を軽減しました。応答生成後や自律行動後に不要なキャッシュを解放しやすくしています。
