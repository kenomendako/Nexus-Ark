# はじめに

Nexus Arkは、AIペルソナと長く暮らすためのローカルアプリです。
会話、記憶、日記、夢日記、目標、外部接続を、ルームごとに保存します。
まずはGemini APIキーを登録し、サンプルルームでチャットできる状態にするのが最短です。

## Nexus Arkでできること

- AIペルソナとチャットし、会話をルームの履歴として残す。
- 日記、エピソード記憶、夢日記、エンティティ記憶を育てる。
- 使わない時間にも、許可した範囲でAIペルソナが自律行動する。
- スマホ向けNexus Ark Lite、Discord、LINE、Twitter (X) など別の入口から同じルームへつながる。
- クローゼット、インベントリ、情景、音声、画像生成などでペルソナとの生活感を整える。

## 基本用語

- **AIペルソナ**: Nexus Arkで暮らすAI人格です。名前、話し方、記憶、目標、外見を持ちます。
- **ルーム**: AIペルソナの生活空間です。会話ログ、記憶、設定、情景、アトリエはルームごとに分かれます。
- **睡眠時記憶整理**: 通知禁止時間帯などに、日記、夢日記、エピソード記憶、索引を整理する処理です。
- **RAG / 記憶の想起**: 過去ログや知識ファイルを検索し、必要な情報を会話へ戻す仕組みです。

## 最初にやること

1. 初回起動の案内に従い、Gemini APIキーを登録します。
2. 左サイドバーの「⚙️ 設定」→「共通」→「🔑 APIキー / Webhook管理」でキーが保存されているか確認します。
3. 中央の「チャット」→「💬 会話」で短いメッセージを送ります。
4. 次に [最初の設定ガイド](01_initial_settings.md) を確認し、送信履歴、記憶の想起、自律行動、通知を必要な範囲だけ調整します。

## Windows版の導入と更新

新しく導入する場合は、ZIPを通常の新しいフォルダーへすべて展開してから、`Start.bat`をダブルクリックします。
ZIPの中から直接起動したり、旧フォルダーへ新版ZIPを上書き展開したりしないでください。初回は専用Pythonと
依存ファイルを自動準備するため、数分かかることがあります。

Windows版は、Python 3.12.16と更新済みの通信ライブラリを使用します。本体用だけでなく更新処理用のPythonも、
起動前に確認・準備します。以前のPythonや会話データを手作業で削除する必要はありません。準備に失敗した場合は
無理に起動せず、表示された案内とエラーを保存してください。

7月公開版や0.66など、0.75より前のWindows版から今回の新版へ更新する場合は、Nexus Arkを
通常終了し、今までのフォルダー全体を別の場所へバックアップしてください。すでに新しい更新方式へ移行済みの
環境も、今回は同じ準備ツールから更新します。0.75以降で初回更新を完了済みの場合は、下の「すでに安全な更新方式へ移行済みの環境」の案内へ進んでください。新版ZIPは既存とは別の新しいフォルダーへ
すべて展開します。今回案内された最新版のZIPを使ってください。以前に取得した準備ZIPは使い回さず、新しい準備ツールでPythonも更新します。

新版フォルダーの`PrepareSecureUpdate.bat`をダブルクリックし、画面のフォルダー選択で今まで使っている
Nexus Arkフォルダーを指定します。終了とバックアップの確認後、専用の取得環境で署名済み更新を検証し、
新版・専用Python・必要なランタイムを準備します。旧アプリや旧Pythonを起動して更新を取得する必要はありません。

別ウィンドウに工程と経過時間が表示されます。ファイルの取得・会話や設定のコピー・依存環境の準備・起動確認には
時間がかかるため、完了または停止の案内が出るまでお待ちください。途中で同じ本体を起動しないでください。
新版の起動確認後にフォルダーを切り替え、**今までのフォルダーの`Start.bat`から新版を自動で起動**します。
初回更新と新しい更新方式への移行まで済むので、旧版の画面で更新・移行をもう一度行う操作は不要です。

旧フォルダー全体は、隣に作られる`.<元のフォルダー名>.nexus-secure-update`内の`previous`へ保全します。
会話・記憶・画像・ノート・設定は新版へ引き継ぎます。本体へ直接追加した自作ツールや独自テーマなどのファイルは
旧フォルダーに残るので、再利用する前に互換性を確認してください。旧本体コードや旧`.venv`を新版へ上書きしないでください。
この保全は、作業前の全体バックアップも保持したまま行います。

停止した場合は本体を自動起動しません。確認コードと案内を保存し、既存フォルダー・全体バックアップ・
初回更新用のフォルダーを移動・削除せず、同じ準備ツールを再実行してください。途中終了で元フォルダーが
見つからない場合は、フォルダー選択で隣の`.<元のフォルダー名>.nexus-secure-update`を選びます。
記録とフォルダーの一致を確認できる場合だけ復旧し、不明な場合はファイルを保持して停止します。

`legacy-bootstrap-secure-release-required`は、指定の更新先に安全な初回更新へ対応した新版がまだない状態です。
旧版を起動して迂回せず、対応する配布物の案内をお待ちください。Python本体の追加セキュリティ更新についても、
配布案内に記載された対応範囲を確認してください。

すでに安全な更新方式へ移行済みの環境も、更新用プログラムの準備が必要と案内された場合は
**最新版ZIPの準備ツール**を使用してください。
本体を通常終了し、フォルダー全体をバックアップしてから、別フォルダーへ展開した最新版の
`PrepareSecureUpdate.bat`で今までのフォルダーを選びます。停止中の既知の更新用プログラムを照合し、
必要な場合はバックアップを残して更新します。起動後は本体の通常更新へ進んでください。
準備が途中で止まった場合はファイルを移動・削除せず、同じ最新版の準備ツールで状態を確認してください。
未知の変更や未完了の本体更新がある場合は、安全のため停止するので、その案内を保存してください。
停止時の確認コードは、起動処理の検出、実行状態の確認不能、アプリのlock、Start.batの不一致、未完了の更新などを
区別します。lockを手動で削除したりファイルを上書きしたりせず、表示された確認コードをお知らせください。


準備に失敗した場合は`update_recovery`、`app.previous`、`.venv.previous`、backupを削除せず、画面の案内を
確認してください。`UpgradeUpdateSystem.bat`は通常の初回手順ではなく、準備に失敗した場合や復旧案内で
指定された場合に使います。

通常更新では、アプリ本体と専用Python環境を一組として切り替えます。新版がローカル起動確認に合格した後だけ
更新を確定し、起動できない場合は直前の版へ戻します。

今回のセキュリティ更新の対応範囲と、画像ライブラリなどの残る注意点は、[トラブルシューティングの「今回の安全対策と残る注意」](11_troubleshooting.md#今回の安全対策と残る注意)もご確認ください。

### 準備ツールより先に旧版の自動更新を押した場合

「更新を確認」だけなら本体の置き換えはまだ始まっていません。通常終了し、フォルダー全体を
バックアップしてから、上の準備ツールの手順へ進んでください。

更新の適用まで始めた場合は、処理中に強制終了せず、完了または停止の案内を保存してください。
本体の番号だけが新版になっても、起動・更新の仕組みや専用ランタイムの準備が済んだとは限りません。
旧方式が残っている場合は、案内された最新版ZIPの準備ツールで今までのフォルダーを選びます。
同じ版の本体が入っていても、署名済みの一式を再取得し、データを引き継いで安全な更新方式へ整えます。
起動できなくても既存フォルダーは残し、通常終了できる状態なら終了してからバックアップしてください。

準備ツールも停止した場合は、確認コードを保存してご相談ください。lock・復旧記録の削除や、
旧Python・旧本体の上書きコピーはしないでください。

### 以前の更新手順の途中から再開する場合

以前の手順で本体更新だけを適用し、「新しい更新方式へ移行」が残っている場合も、まず通常終了し、
全体バックアップを残して上記の最新版準備ツールで作業を再開してください。今回の準備ツールで更新が完了した後は、
画面から更新・移行を重ねて行う必要はありません。元のフォルダーの`Start.bat`を引き続き使います。

中断状態の復旧を案内された場合は、その指示を優先し、旧フォルダーや復旧記録を手作業で上書き・削除しないでください。
更新・再起動後はページを一度再読み込みしてください。Lite独立モードやCloudflareの登録・利用は任意です。

### Windowsのブラウザ機能（Liteを使わない場合も）

本体更新後、左サイドバーの「🔄 アップデート・再起動」内にある「ブラウザ機能の準備（Windows）」で
「ブラウザ機能の準備を確認」を押します。最初に「ブラウザ機能の状態を確認しています。表示まで少しお待ちください。」と表示されます。実物の実行環境を確認した後だけ、実際のNode版や準備完了の表示に変わります。初回の準備が必要な場合だけ「署名済みブラウザ用Nodeを準備」が表示されるため、
内容を確認してから押してください。現在の本体に対応した、安全性を確認済みのブラウザ用実行環境を取得します。
完了後、もう一度「ブラウザ機能の準備を確認」を押して、
「✅ ブラウザ機能の準備が完了しました」と表示され、その下に「Nexus Arkを通常どおりご利用いただけます。」と表示されることを確認してください。Lite独立モードの初回設定は、完了表示とは別に「外部接続」→「Lite・お出かけ」→「初回設定・接続管理」から進めます。

この準備にCloudflareアカウント、AIキー、ペルソナの設定は必要ありません。導入済みの実行環境に修復が必要な
場合は手作業でファイルを置き換えず、同じ「🔄 アップデート・再起動」から本体の署名済み更新を確認してください。
一般公開版では更新先を本番のまま使い、設定ファイルやJSONの更新先を変更しません。

## データの保存場所

ルームの会話や記憶は `characters/<ルーム名>/` に保存されます。
共通設定は `config.json`、ユーザー共通の外見設定は `user_closet/` に保存されます。
アプリ更新時も、これらのユーザーデータを保持する前提で運用します。
