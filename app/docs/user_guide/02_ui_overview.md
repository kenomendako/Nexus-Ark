# 画面構成と基本操作

Nexus Arkの画面は、左サイドバー、中央タブ、右サイドバーの3つに分かれます。

## 左サイドバー

左サイドバーは「設定」というサイドバーです。
一番上の「ルームを選択」で、会話するルームを切り替えます。
ルームの新規作成や外部ログのインポートが完了しても、会話中のルームは自動では切り替わりません。続けて使う場合は、作成・インポートしたルームをここで選んでください。
切替中はチャット欄の上に進捗バナーが表示されます。ページをスクロールしていても中央カラム上部に留まり、設定と補助情報の読込が完了すると自動で消えます。

主なアコーディオンは次の通りです。

- 「⚙️ 設定」: 共通設定、個別設定、デザイン設定。
- 「⏰ 時間管理」: アラーム、タイマー。
- 「🧑‍🤝‍🧑 グループ会話」: 複数ルームの会話。
- 「🏠 チャットルームの作成・管理」: ルームの作成、管理、外部ログのインポート。
- 「🛠️ チャット支援ツール」: スクリーンショット用の文字置き換え、ログ修正。
- 「🔄 アップデート・再起動」: 更新確認、リリースノート、アプリの再起動。「🔁 アプリを再起動」を押すと、確認後に再起動して同じタブが自動でリロードされます。
- 「📖 使い方ガイド」: このガイドをアプリ内で開きます。

## 中央タブ

中央の主なタブは次の通りです。

- 「チャット」: 会話、ログ管理、コンテキスト管理。
- 「知識」: 知識ベース (RAG) と Skills / 手順記憶。
- 「記憶・ノート」: システムプロンプト、コアメモリ、日記、夢日記、エピソード記憶、ノート。
- 「自律行動」: 自律行動（このルーム）、ウォッチリスト（URL一覧・グループ管理）、アトリエ・委任。
- 「外部接続」: Twitter (X)、Discord / LINE、拡張ツール、API Gateway / Lite。
- 「クローゼット・アイテム」: アイテム作成、インベントリ、クローゼット。
- 「ワールド・ビルダー」: ルームの世界設定を、構造化エディタまたはRAWテキストで編集。
- 「お出かけ」: 外部AIツール用のエクスポートと帰宅インポート。
- 「デバッグコンソール」: 内部ログ表示。

画面の幅が狭いときは、右端の「…」に残りのタブが入ります。

## 右サイドバー

右サイドバーは「情景・プロフィール」です。
「🖼️ プロフィール・情景」から、アバター、表情、仮想現在地、一時的現在地を扱います。

主な場所は次の通りです。

- 「🖼️ アバター・表情を管理」: プロフィール画像、動画アバター、表情差分。
- 「🏠 仮想現在地」: ルーム内の現在地と情景。
- 「🌄情景設定・生成」: 情景画像生成、季節・時間、カスタム情景画像。
- 「📍 一時的現在地」: 現実の写真や説明を一時的にペルソナへ共有。

## ルーム単位の考え方

多くの設定はルーム単位です。
AIモデル、送信コンテキスト、情景描写、音声、カレンダー、クローゼット、自律行動、委任は、今選んでいるルームにだけ効く項目があります。

一方で、APIキー、プロバイダ、通知サービス、天気、Googleカレンダーの認証、API Gatewayなどは共通設定です。
迷った時は、左サイドバーの「⚙️ 設定」内で「共通」タブか「個別」タブかを見て判断します。

## 読み込み・更新ボタン

起動とタブ切り替えを軽くするため、一覧や記憶の内容は必要な時だけ読み込む画面があります。
各タブやアコーディオンの上部に、次のボタンが表示されます。

- 「🔄 読み込む」: まだ表示していない内容を初めて読み込みます。
- 「🔄 最新の状態に更新」: 保存済みの最新内容を読み直します。
- 「🔄 一覧を更新」: 一覧だけを更新し、編集欄の内容は変更しません。

「最新の状態に更新」の近くに未保存内容についての注意書きがある場合、編集中の内容は失われます。必要な内容を保存してから更新してください。

## 設定の保存方式

設定ブロックの上部には、保存方式が表示されます。

- 「✓ 変更は自動保存されます」: 値を変えると保存されます。
- 「💾 …を押してください」: ブロック末尾の保存ボタンを押す必要があります。
- 「プレビュー」: 見た目にはすぐ反映されますが、保存ボタンを押すまで次回起動時の設定にはなりません。

「個別」設定の多くは自動保存ですが、チャットのスタイル・文字サイズ・行間とデザイン設定はプレビュー後に明示保存します。
