# 最初の設定ガイド

初回起動後に確認するとよい設定を、優先順にまとめます。
迷った場合は「まずこれだけ」の値で始め、会話量やAPIコストを見ながら調整してください。
## まずこれだけ

| 項目 | 場所 | 推奨 |
|---|---|---|
| Gemini APIキー | 左サイドバー「⚙️ 設定」→「共通」→「🔑 APIキー / Webhook管理」→「Gemini APIキー」 | 1本以上登録 |
| 有料キー区分 | 同じ場所の「有料プランのキーを選択」 | 有料キーだけチェック |
| 会話モデル | 「⚙️ 設定」→「共通」→「⚡ AIモデルプロバイダ設定（デフォルト）」 | まずGoogle (Gemini Native) |
| 送信する履歴 | 「⚙️ 設定」→「個別」→「📡 送信コンテキスト設定」→「APIへの履歴送信（短期記憶の長さ）」 | 短めから開始 |
| 記憶の想起 | 同じ場所の「記憶の想起（長期記憶）を有効化」 | ON |
| 自律行動 | 中央「自律行動」→「自律行動（このルーム）」→「✨ 自律行動設定（このルーム）」 | 最初はOFFでもよい |
| 通知禁止時間帯 | 同じ場所の「🌙 通知禁止時間帯（このルーム）」 | 00:00〜07:00 |
| 通知サービス | 「⚙️ 設定」→「共通」→「📢 通知サービス設定」 | 使う人だけ設定 |

## APIキー

Gemini APIキーは、左サイドバーの「⚙️ 設定」→「共通」→「🔑 APIキー / Webhook管理」→「Gemini APIキー」で追加します。
キー名は管理用の名前です。APIキーの値は端末内の `config.json` に保存されます。

有料プランのキーを登録した場合は、同じアコーディオン内の「有料プランのキーを選択」でチェックします。
無料キーと有料キーを混ぜる場合、無料キーの制限に達した時だけ有料キーを使う運用にできます。

## 送信するログの量

ルームごとの設定は、左サイドバーの「⚙️ 設定」→「個別」→「📡 送信コンテキスト設定」にあります。
「APIへの履歴送信（短期記憶の長さ）」は、直近の会話をどれくらいAIへ送るかの設定です。
長くすると文脈は増えますが、APIコストと待ち時間も増えます。

新しく作成したルームでは、履歴送信は「本日分」、「本日分が長くなったら自動で要約する」はONで始まります。
その日の会話をまるごと覚えたまま話せて、長くなった分は自動要約で送信量が抑えられる設定です。
APIコストを細かく管理したい場合は、「最新 N件」への変更や自動要約のOFFもここでできます。
（以前から使っているルームの設定は変わりません。）

## 記憶の想起

「記憶の想起（長期記憶）を有効化」をONにすると、AIペルソナが記憶や過去ログから関連情報を検索します。
長く使うルームではON推奨です。

別チャットサービスから引き継いだ思い出や、会話中に参照してほしい情報をナレッジへ保存している場合は、同じ場所の「ナレッジも自動想起に含める（関連時のみ）」もONにします。この設定はルームごとに保存され、初期値はOFFです。ONにしてもナレッジ全文を毎回送るのではなく、会話に関連する部分だけを最大3件検索します。手動でナレッジを検索する機能には影響しません。
ただし索引作成や検索にはEmbeddingモデルの設定と計算時間が関わるため、初期設定直後に重い処理が走る場合があります。

Embeddingモデルは「⚙️ 設定」→「共通」→「🔧 内部処理モデル設定」→「🧠 エンベディング（ベクトル化）」で設定します。
モデルを変更した時は、中央「記憶・ノート」→「記憶」→「🛠️ 記憶のメンテナンス (手動実行)」で索引を再構築してください。

## 自律行動

自律行動は、ユーザーが入力していない間にAIペルソナが考えたり、記憶を整理したり、検索やノート更新を行う機能です。
最初はOFFで始め、会話や記憶の動きに慣れてからONにしても問題ありません。

ONにする場合は、中央「自律行動」→「自律行動（このルーム）」→「✨ 自律行動設定（このルーム）」を開きます。
「自律行動モードを有効化」をONにし、「無操作判定時間（分）」と「自律行動タイマーの最小間隔・クールダウン（分）」を長めに設定すると、API呼び出しが増えすぎにくくなります。無操作判定時間は最低待機時間で、経過後もAIペルソナの動機が十分な場合だけ行動します。止める場合は時間を延ばすのではなく、自律行動モードをOFFにしてください。

## 通知

通知は、アラームやAIペルソナからの声かけをPCや外部サービスへ出す機能です。
左サイドバーの「⚙️ 設定」→「共通」→「📢 通知サービス設定」で、アラーム用と通常通知用のサービスを選びます。
PushoverやDiscord Webhookのキーは「🔑 APIキー / Webhook管理」で登録します。

通知を控えたい時間帯は、中央「自律行動」→「自律行動（このルーム）」→「✨ 自律行動設定（このルーム）」→「🌙 通知禁止時間帯（このルーム）」で設定します。
この時間帯は睡眠時間として扱われ、睡眠時記憶整理のきっかけにもなります。

## スマホ利用

スマホから使う場合は、中央「外部接続」→「API Gateway / Lite」を開きます。
「API設定」でAPI Gatewayを有効化し、Tokenを生成して保存します。
「Nexus Ark Lite 接続情報」に表示されるURLをスマホで開きます。

スマホの録音やPWA通知にはHTTPSが必要になることがあります。
同一LAN、Tailscale HTTPS、Tailscale Funnelなど、本人が管理できる接続経路で使ってください。
