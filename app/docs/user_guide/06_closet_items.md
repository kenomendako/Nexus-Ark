# クローゼット・アイテム

クローゼット・アイテム機能では、ユーザーとAIペルソナの所持品、服装、外見参照を管理できます。
画像生成やチャット応答に、現在の装いを反映できます。
中央「クローゼット・アイテム」タブから操作します。

## アイテム作成

中央「クローゼット・アイテム」→「アイテム作成」で、通常アイテムと食べ物アイテムを作れます。

- 「通常アイテム」: 装飾品、雑貨、家具、道具など。
- 「食べ物」: 味覚、香り、食感、温度、共感覚イメージを持つ食べ物。

どちらも「🎨 画像を生成」から画像生成プロンプトと参照画像を指定できます。
「✨ AIで詳細を生成」または「✨ AIで味覚データを生成」を使うと、説明文や味覚データを補助生成します。

## インベントリ

中央「クローゼット・アイテム」→「インベントリ」では、ユーザーとペルソナの所持品を切り替えて確認します。
表示対象は「ユーザー」または「ペルソナ」です。

主な操作は次の通りです。

- 「📝 編集」: 選択アイテムを編集。
- 「👯 複製」: 選択アイテムを複製。
- 「🗑️ 削除」: 選択アイテムを削除。
- 「🎁 相手に渡す」: ユーザーとペルソナの間でアイテムを渡す。

「👕 クローゼットに登録（着用可能にする）」を使うと、選択したアイテムを服やアクセサリーとして登録できます。

## クローゼット

中央「クローゼット・アイテム」→「クローゼット」では、表示対象を「ユーザー」または「ペルソナ」に切り替えます。

ユーザー側には「🪞 姿見」と「📋 クローゼット管理」があります。
「共通既定」は全ルーム共通のユーザー外見です。
「このルーム」は現在のルーム専用のユーザー外見です。
「共通設定を使う」をONにすると、ルーム専用設定ではなく共通既定を使います。

ペルソナ側にも「🪞 姿見」と「📋 クローゼット管理」があります。
ペルソナのベース外見、参照画像、現在の装いメモ、着用中アイテムを管理できます。

## 姿見

「🪞 姿見」では、現在の外見と装いを確認します。
生成した「現在の姿」は姿見の先頭へ保存され、アプリを再起動した後やルームを切り替えた後も表示されます。
外見や装いを変更すると更新案内が表示されます。「🔄 この姿をもとに再生成」は保存済みの姿を引き継ぎ、「🎨 基準画像から作り直す」は保存済みの姿を参照せずに新しく生成します。生成に成功した画像が、新しい「現在の姿」として保存されます。

現在の姿を更新するときは、保存済みの現在の姿を主な参照画像として使い、着用中アイテムとベース参照画像で補います。
まだ現在の姿がない場合は、ベース参照画像と着用中アイテム画像を使用します。参照画像は「現在の姿」を作るための基準資料として、姿見内の共通既定／このルーム設定から追加・削除できます。

ユーザーの外見を設定しておくと、ユーザーが写る画像生成や、ペルソナの会話内での描写が安定しやすくなります。

## 部位カテゴリ

クローゼットの部位カテゴリには、トップス、ボトムス、靴、アクセサリー、ワンピース、アウター、その他などがあります。
未知の部位は安全に「その他」として扱われます。
