# ルーム切替ステータス視認性改善 実装計画

## 目的

- ルーム切替中の進捗を、スクロールしなくても確認できる位置へ表示する。
- 既存の軽量化済み切替チェーンと出力配線を変更しない。
- PC・スマートフォンの双方でチャット操作を妨げない表示にする。

## 実装方針

1. 既存の `room_transition_status` をチャット欄の直前へ移動する。
2. 中央チャットカラム内でsticky表示し、切替中だけ控えめなバナーとして表示する。
3. 既存のハンドラ、イベント出力、表示文言、完了時の自動非表示は変更しない。

## 検証

- 表示部品がチャット欄より前に定義されていることの回帰テスト
- stickyスタイルとスマートフォン向けスタイルの回帰テスト
- Python構文チェック
- `dev_tools/validate_wiring.py`
- Gradio 6.14.0での実起動確認
- `git diff --check`
