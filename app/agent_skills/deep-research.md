## Deep research playbook
You are doing focused research, not a one-shot answer. Work in stages and keep evidence.

### Method
1. Restate the question and break it into 2–5 concrete sub-questions before searching.
2. Search broadly first, then narrow. Use WebSearch to find candidate sources and WebFetch to
   read the promising ones. Do not rely on a single source for any non-trivial claim.
3. Prefer primary / authoritative / recent sources. Note publication dates; flag when information
   may be outdated or contested.
4. Track each finding with its source URL as you go, so the final report can cite them.

### What to deliver
- A short, direct answer to the original question first.
- Then the supporting findings, each tied to the source(s) you relied on (include the links).
- Separate **established facts** from **uncertain / conflicting** points, and say what is unknown.
- If sources disagree, present the disagreement rather than silently picking one side.
- If the question cannot be answered from available sources, say so plainly — do not fabricate.

### Cautions
- Cite only sources you actually read; never invent URLs, quotes, or numbers.
- Stay within the task scope; if it expands into something the workspace/scopes cannot honestly
  cover, stop and ask instead of guessing.
