# 🗓️ Googleカレンダー連携 セットアップガイド

ご自身のGoogleカレンダーをペルソナが参照できるようにする手順です。
予定はバックグラウンドで同期され、ローカルに保存されたものを高速に読み取ります。

連携には、**ご自身のGoogle Cloudプロジェクトで発行した認証情報（Client ID / Client Secret）** が必要です。
Nexus Ark側に共通の認証情報は埋め込んでいません（あなたのカレンダーは、あなた自身の認証情報でのみアクセスされます）。

> ⏱️ 所要時間の目安: 初回のGoogle Cloud側の準備に10〜15分ほど。2回目以降は不要です。

---

## ⚠️ 最初に知っておくと安心なこと

### 「このアプリは Google で確認されていません」と出ても大丈夫

認証URLを開くと、**「このアプリは Google で確認されていません（This app isn't verified）」** という警告が表示されます。

**これは異常ではありません。** ここで言う「アプリ」とは、**あなたがこのガイドのパート1でGoogle Cloud上に作成した認証情報（OAuthクライアント）** のことです。Googleの「確認（verification）」という審査をまだ受けていないため、この警告が出ます。

- この確認審査は、**作成した認証情報を不特定多数の他人にも使わせる場合**にだけ必要なものです。**ご自身のカレンダーを、ご自身のNexus Arkから読むだけなら受ける必要はありません。**
- あなたがご自身のGoogleアカウントで作成し、あなたしか使わない認証情報なので**安全**です。
- **通過方法**: 警告画面の **「詳細（Advanced）」→「（アプリ名）に移動」**（または「安全ではないページに移動」）をクリックすれば、そのまま先へ進めます。
  - ※ここで表示される「（アプリ名）」は、パート1ステップ3の「ブランディング」で設定した名前です。

### リフレッシュトークンの「7日問題」

後述のOAuth同意画面を **「テスト」** のままにしておくと、Googleの仕様で**約7日でログイン情報（リフレッシュトークン）が失効**し、再認証が必要になります。

- お試し中は「テスト」のままでOKです。
- **継続して使う場合**は、Google Cloud側で **アプリを「本番（In production）」に公開**してください。自分だけの利用なら、この公開に審査は不要です（公開後も上記の「未確認」警告は出ますが、トークンは失効しなくなります）。

## 🛠️ パート1: Google Cloud側の準備（初回のみ）

[Google Cloud Console](https://console.cloud.google.com/) を開いて進めます。

### ステップ1: プロジェクトを用意する
画面上部からプロジェクトを新規作成（または既存のものを選択）します。

### ステップ2: Google Calendar API を有効にする
1. 左メニュー **「APIとサービス」→「ライブラリ」** を開きます。
2. **「Google Calendar API」** を検索して開き、**「有効にする」** を押します。

> これを忘れると、認証は通っても予定の同期でエラーになります。

### ステップ3: 認証の同意画面を設定する（Google Auth Platform）
左メニュー **「APIとサービス」→「OAuth同意画面」**（新しい画面では **「Google Auth Platform」**）を開きます。メニューはおおよそ次の構成です。

- **ブランディング**: アプリ名と、サポート用メールアドレスを入力します。
- **対象（Audience）**:
  - ユーザーの種類は **「External（外部）」** を選びます。
  - **「テストユーザー」に、ご自身のGoogleアカウント（連携したいカレンダーのアカウント）を追加** します。← ここが重要です。追加し忘れると認証時にブロックされます。
- （継続利用するなら、後でこの画面の **「アプリを公開」** で本番公開できます ＝ 7日失効の回避）

### ステップ4: OAuthクライアントを作成する
1. 左メニュー **「クライアント」**（または「認証情報」）を開き、**「OAuth クライアントを作成」** を押します。
2. **アプリケーションの種類で「デスクトップ」（デスクトップアプリ）を選びます。** ← 必ずこれを選んでください。
3. 名前は任意（例: Nexus Ark）。**「作成」** を押します。
4. 作成後に表示される **「クライアントID」** と **「クライアントシークレット」** をコピーします（後から「クライアント」一覧で再表示・ダウンロードもできます）。

> 種類が「デスクトップ」でないと、アプリ内の認証で `redirect_uri_mismatch` エラーになります。

---

## 🔑 パート2: Nexus Ark側で認証する

左サイドバー **「⚙️ 設定」→「共通」タブ →「🗓️ Googleカレンダー連携設定」→「🔑 OAuth認証」** を開きます。

### ステップ1: 認証情報を入力
パート1でコピーした **Client ID** と **Client Secret** を、それぞれの欄に貼り付けます。

### ステップ2: 認証URLを生成して承認する
1. **「① 認証URLを生成」** を押します。「認証URL」欄にURLが表示されます。
2. そのURLをブラウザで開きます。
3. 連携したいGoogleアカウントを選びます。
4. **「このアプリは Google で確認されていません」** が出たら、上の説明のとおり **「詳細」→「（アプリ名）に移動」** で進みます。
5. カレンダーへのアクセスを **「許可」** します。

### ステップ3: 認証コードをコピーして貼り付ける
1. 承認すると、ブラウザが **`http://localhost/?code=……`** へ移動し、**「このサイトにアクセスできません」** と表示されます。**これは正常です**（待ち受けサーバーがないだけ）。
2. ブラウザの**アドレスバーを見て、`code=` の後ろの値**をコピーします。
   - `code=` の直後から、**次の `&`（`&scope=` の手前）まで**をコピーしてください。
3. Nexus Arkの **「② 認証コード」** 欄に貼り付け、**「③ 認証する」** を押します。
4. ステータスが **「接続済み」** になれば認証成功です。

### ステップ4: カレンダーを選んで有効化する
1. **「🔄 カレンダー一覧を取得」** を押します。
2. **「同期対象カレンダー」** で、ペルソナに見せたいカレンダーにチェックを入れます。
3. **「Googleカレンダー連携を有効にする」** をオンにします。
4. **「Googleカレンダー設定を保存」** を押します。

---

## ✅ 動作確認

- 保存後、**最大1分ほどでバックグラウンド同期**が走り、予定がローカルに取り込まれます（初回はすぐ同期されます）。
- その後、チャットでペルソナに **「今日の予定は？」「午後は空いてる？」** などと聞いてみてください。
- 非公開にしたい予定は、タイトルに `[Private]` や `[非公開]` を入れる（または除外キーワードを設定する）と、ペルソナからは「（非公開の予定）」として隠されます。空き時間の判定では「埋まっている」扱いになります。

---

## 🩺 うまくいかないとき

| 症状 | 対処 |
|---|---|
| 「このアプリは確認されていません」で進めない | 異常ではありません。「詳細」→「（アプリ名）に移動」で進めます |
| `redirect_uri_mismatch` エラー | OAuthクライアントの種類が **「デスクトップ」** か確認してください |
| 「③ 認証する」で失敗する | コードのコピー範囲を確認（`code=` の後ろ〜`&scope` の手前まで）。URL全体を貼っていないか確認 |
| 認証はできたが予定が出てこない | 「有効化オン＋保存」済みか、同期対象カレンダーを選んだか、1分ほど待ったかを確認 |
| 同期でエラーになる | パート1ステップ2の **Google Calendar API の有効化** を忘れていないか確認 |
| 数日でまた認証を求められる | 「テスト」公開ステータスの**7日失効**です。継続利用するならアプリを**「本番」に公開**してください |
| 認証をやり直したい | 「認証を解除」を押してから、再度①〜③をやり直してください |
