## 初回更新で止まった方向け：読み取り診断ツール

Nexus Ark 0.5.0.89への初回更新で、`legacy-bootstrap-verification-failed` などの確認コードが出た方に、サポートから案内する診断ツールです。

**本体の新バージョンや修復ツールではありません。問題なく更新できた方の実行は不要です。Nexus Ark本体の最新版は0.5.0.89のままです。**

### 使い方（Windows）

1. 下のAssetsから **`NexusArk-InspectLegacyBootstrap-20261101.zip`** をダウンロードします。
2. 今まで使っていたNexus Arkフォルダーとは **別の場所** にZIPを展開します。
3. **`InspectLegacyBootstrap.bat`** を実行します。
4. 選択画面で、**今まで使っていたNexus Arkフォルダー（Start.batのある場所）** を選びます。
5. 黒い画面に出た診断結果を、コピーまたは画像でサポートへ個別にお知らせください。その後は画面を閉じて構いません。

既存フォルダー、バックアップ、隣の復旧フォルダーは残してください。更新の再試行や手動のフォルダー移動は、診断結果の確認後にご案内します。

### このツールが確認するもの

- 旧フォルダーと初回移行用フォルダーの有無
- 記録された処理状態と本体の版番号
- フォルダーの現在の使用中・権限エラーの手掛かり（Windowsのエラー番号）

**選択したNexus Arkやバックアップの削除・移動・書込み、アプリの起動・終了、外部通信は行いません。** 会話本文・APIキー・個人設定・フォルダーの実名は診断結果に含めません。結果の送信も自動では行いません。

診断で問題が見つからなくても、失敗当時の状態や次回の更新成功を保証するものではありません。スクリプトはZIP内で確認できます。Windows PowerShell 5.1で、共有ロックの検出・診断対象のファイル内容不変・リンク拒否などを検証済みです。

通常の自動更新用 `InspectFailedUpdate.bat` / `RecoverFailedUpdate.bat` とは用途が異なります。本体の自動更新には配信されません。
